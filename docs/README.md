# 项目文档

本目录只维护 F1 个人项目的长期知识，与公司项目、个人工作日志及公司汇报隔离。项目级协作边界见 [AGENTS.md](../AGENTS.md)。

| 需要做什么 | 阅读文档 |
| --- | --- |
| 安装、配置、首次运行 | [项目 README](../README.md) |
| 修改代码、提示词或测试 | [开发规范](development.md) |
| 理解数据流、质量关卡和状态管理 | [架构文档](architecture.md) |
| 部署、查看定时任务、排查失败 | [运维手册](operations.md) |

维护约定：

- `AGENTS.md` 保持简短，存放项目边界、关键规则和导航。
- `README.md` 面向使用者，保留安装与常用命令。
- 开发规则、架构和运维知识分别更新对应文档，避免重复复制大段内容。
- 文档描述实际实现；计划与建议必须标明，不能写成已具备的能力。
- `REVIEW_*.md` 是历史审阅材料，不是当前开发规范；现状以代码、配置和上述维护中的文档为准。
- 不在这里新增日常工作日志。测试输出、草稿和采集上下文属于运行产物，不纳入公司工作记录。
